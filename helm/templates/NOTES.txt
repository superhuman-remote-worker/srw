Encryption key
==============
API keys and LLM endpoint credentials (user_api_keys, system_api_keys,
llm_endpoints.api_key) are encrypted at rest using APP_ENCRYPTION_KEY
in Secret `{{ include "srw.secretName" . }}`. If this key is lost, all
stored credentials become unrecoverable.

Back it up now:

  kubectl -n {{ .Release.Namespace }} get secret {{ include "srw.secretName" . }} \
    -o jsonpath='{.data.APP_ENCRYPTION_KEY}' | base64 -d

orchestrator will refuse to start without it.

{{- if .Values.llm.seed.enabled }}

LLM seed
========
Helm will run a one-shot seed Job (`{{ include "srw.fullname" . }}-llm-seed`)
post-install and post-upgrade. It inserts provider keys, endpoints and
catalog rows, and pins default models (llm.seed.defaults), only where they
are absent — existing rows and pins, whether previously seeded or set via
Admin → Models, are never overwritten. Entries declared with
`reconcile: true` are the exception: those are re-applied on every upgrade
and shown with a "Helm" badge in Admin → Models.

Inspect the run:

  kubectl -n {{ .Release.Namespace }} logs job/{{ include "srw.fullname" . }}-llm-seed
{{- end }}

Bundled object store (Garage) — NOT FOR PRODUCTION
==================================================
A single-node Garage S3 store is enabled. It has NO replication or erasure
coding and is bound to one PVC ({{ include "srw.fullname" . }}-garage-data).
It backs workspace snapshots (bucket "{{ .Values.s3.bucket }}") and the virtual
workspace tier (bucket "{{ .Values.garage.buckets.workspaces }}").

For production, just point at an external S3 — setting s3.endpoint turns this
bundled store off on its own (garage.enabled defaults to auto). Set
garage.enabled=false only to run with NO object store at all, which disables
durable Canvas presentations, workspace snapshots, and the virtual tier.
  - s3.endpoint / s3.bucket                 (snapshots)
  - virtualWorkspace.s3.endpoint            (virtual tier)

Inspect the one-time bootstrap (layout + buckets + keys):
  kubectl -n {{ .Release.Namespace }} logs job/{{ include "srw.fullname" . }}-garage-bootstrap
