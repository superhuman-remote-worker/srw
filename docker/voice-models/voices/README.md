# Reference voices for the `cascade-gpu` TTS

Qwen3-TTS Base speaks in the voice of a short reference clip. The audio
adapter (`../audio_adapter.py`, llama.cpp) loads every `<name>.wav` here;
the PyTorch server (`../qwen_tts_server.py`) every `<name>.wav` that has its
transcript beside it as `<name>.txt`. The profile picks one by name
(`tts.voice`).

| Voice | Clip | Made how |
|---|---|---|
| `de-1` (`de-1.txt`: its words, for the PyTorch server's clone prompt) | 3.7 s, 24 kHz mono, "Guten Tag, hier ist die Rezeption vom Hotel Beispielhof." | Generated by Qwen3-TTS 12Hz 1.7B Base (Apache-2.0; GGUF Q8_0 on llama.cpp b11783) **without** a reference: `/tts` with `lang: de`, `seed: 4`; the first sentence of the take. A synthetic voice the model made up; no real person's voice was recorded or cloned. |

How it was chosen (WP4, local_voice_gateway.md §6.2): eight seeds rendered
the same German text; every take was clear to the judge (Qwen3-ASR 0.6B)
after an 8 kHz G.711 leg. Seed 4 is a calm female voice (median pitch about
190 Hz, 2.6 words/s) that stayed the same voice when cloned onto other
sentences. Through G.711 the judge then got 39 of 42 test lines word for
word (word error rate 0.015).

Adding a voice: a few seconds of clean speech, mono WAV, that the operator
has the rights to, and never a clip of a real person: make it the way
`de-1` was made. These clips are configuration, not call audio (A5 keeps
call audio off disk).
